# Phase 5 — Location Detail Page

## Goal

Build the location page — the site's primary sales asset per DESIGN.md §1, 23.

## Read first

[DESIGN.md](../DESIGN.md) §8 (location detail page in full), §23 (the discovery funnel this
page sits in the middle of).

## Build

- Hero: full assembled-environment photography, location name + one-line description, two
  CTAs ("Shop the Complete Set" / "Explore the Pieces").
- Story/use-case section: what the environment supports (social, combat, exploration,
  markets, inns, ambushes) — a short paragraph or tag list, not a wall of copy.
- Included terrain: grid of the individual products that make up this location, each
  linking to its real product page (built in Phase 4).
- Build-your-own tiers: Complete Set, Building Bundle, Individual Pieces — three distinct
  price/commitment options, visually differentiated but not competing for equal attention
  (Complete Set is the primary path per DESIGN.md §23's funnel).

## Don't build

Collection pages, designer pages, cart/checkout logic beyond linking into the (still
UI-only) add-to-cart pattern from Phase 4.

## Acceptance criteria

- Page reads as editorial/cinematic first, transactional second (DESIGN.md §8's framing).
- Included terrain grid links resolve to real product pages built in Phase 4.
- All three purchase tiers present and distinct.
- PLAN.md status updated; committed.
