    Why these never expire. Most "free QR code" sites hand you a code that points
    at their own short link, then redirect it to you — and when the trial ends or the site shuts
    down, the redirect stops and every printed copy goes dead. The codes made here hold the
    actual link, text, Wi-Fi login or contact card in the pattern itself. Nothing is hosted,
    tracked or counted, there's no account to lapse, and it all runs in your browser — the code
    you print today will scan the same way in twenty years.
    
  
    The one thing a static code can't change after it's printed is what it says, so a Link code
    works as long as that web page stays up.
